# AgentHub 0.2.3：原生使用闭环

普通 CLI 统一使用当前普通 Windows 用户执行。新旧普通任务可跨目录读写、联网及调用本机软件，不再逐目录询问信任。任务历史、位置、锁、取消、续接、记忆采纳和资源来源继续保留。

## 安装与升级

收到 wheel 后无需克隆源码。在普通终端运行：

```powershell
Get-FileHash .\agenthub_system-0.2.3-py3-none-any.whl -Algorithm SHA256
uv tool install --force --python 3.11 ".\agenthub_system-0.2.3-py3-none-any.whl[cli]"
agenthub --version
agenthub doctor
```

校验值应与配套 `.whl.sha256` 一致。新用户运行 `agenthub init` 配置模型。老用户保留原配置，退出使用同一状态目录的其他 CLI 后运行 `agenthub state upgrade`；不要重新初始化。

本地 schema 保持 v6，支持 v1–v5 直接升级；v6 原地保留。升级使用 SQLite backup API 备份，再单事务迁移。旧 trust 记录和实验权限表不删除，但 trust 不再控制普通任务。记忆、遗忘抑制、资源、历史及凭据引用保持。升级不会修改 ACL 或初始化管理员组件。

## 日常操作

```powershell
agenthub -p "读取 D:\资料\说明，在 E:\实验\project 修改代码，用项目虚拟环境运行测试"
agenthub -r                         # 任意目录列出旧任务
agenthub -c                         # 继续最近任务
agenthub --resume ID --cwd E:\实验\project
```

`/cd PATH` 修改保存位置；`/add-dir PATH` 添加参考目录。两者不授予权限。
`process.run` 接受程序、参数数组和 cwd；`software.discover` 只读发现项目虚拟环境、PATH 程序及 CLI 解释器。软件登记可选，原 `software.run` 保留指纹检查。批处理脚本使用 PowerShell。

正常网络和缓存可用；依赖安装由用户任务驱动，不在启动时自动执行。默认命令超时 120 秒，仍受 Run 剩余时间约束。Ctrl+C 清理受管理的进程树，实际副作用保留供续接核实。OS 拒绝会成为工具失败，不自动提权。宿主已提升时拒绝模型任务和工具管理，需改用普通终端；只读历史、配置和诊断仍可使用。

## 暂缓的隔离功能

LPAC 不作为 0.2.3 正式功能。旧受限任务及曾采用受限默认策略的环境不自动降级，用户须明确转换：

```powershell
agenthub --resume ID --sandbox current-user
# 曾采用受限默认策略的环境，新任务也须显式指定：
agenthub --sandbox current-user
```

`permissions`、`sandbox doctor` 保留只读检查；新的受限 setup/self-test、授权和启用入口暂停。
普通模式拒绝 read-dir/write-dir/custom 权限参数。`trust add/remove` 返回停用说明，不能当作有效撤权。本版没有目录黑名单、强文件/网络隔离或任意脚本绝对防提权保证。

已有管理员组件、ACE 和准备记录不自动清理。维护前先查看 `sandbox doctor`，再按记录显式使用 `sandbox repair/uninstall`；不能随意恢复旧 DACL。正常使用不触发这些入口或 UAC。

## 回退与交付

退出所有 CLI，保存升级后状态，再用生成备份时的旧 wheel 和升级前 `.bak` 恢复。旧版本拒绝 v6；备份不含升级后的新记录。不要只复制仍在运行的 SQLite 主文件而遗漏 WAL。

共享包及后端均为 0.2.3，前端和桌面客户端保留自身发行版本。源码与 wheel 对应关系、实际验证范围见[验收记录](../acceptance/native-user-experience-0.2.3.md)。未发布远程 Release，未上传包。
