# AgentHub 0.2.1：L2 基础记忆

本轮在 L1 本机环境身份之上实现独立于任务历史的知识库，Python 主执行链、资源授权与任务上下文继续保留。实施顺序为存储和显式管理、实际模型输入、候选及终态 outbox、安装与宿主验收。L3 资源知识库、向量检索、额外摘要模型、常驻服务、多助手共享、Web 记忆界面不在本轮范围。

## 行为

用户通过 `memory add` 或 `/memory add` 保存立即生效。模型只有 `memory.search`、`memory.read`、`memory.propose`；自然语言要求“记住”也须产生候选并等待采纳。任务结束提示待检查数量，不自动弹审批。

记忆按环境 UUID 和默认助手 `local` 隔离，不按任务目录隔离。指定目录的适用范围只表达知识在哪些位置相关，不授予文件访问权。采纳后撤销目录信任不会自动撤销这条知识，用户须停用或遗忘。跨任务不复制原会话全文，不回扫历史 Run 提炼知识。

## 实现边界

| 层 | 职责 |
| --- | --- |
| contracts/memory.py | 记录、修订、来源、候选、访问上下文、装配条目和读写处理端口 |
| subsystems/memory | 校验、指纹、中文/英文词项、确定性选择、每请求复核和模型工具 |
| adapters/storage | schema v4、CAS、索引、候选、管理事件、来源抑制与终态 outbox |
| subsystems/context | 返回最终消息、系统提示、实际使用修订和裁剪诊断；优先移除可选记忆 |
| CLI | 表单、列表、来源详情、采纳、显式脚本参数、环境绑定与 Run 组装 |

记忆块是带来源的资料，不是额外系统指令，不写入成功任务上下文。每个 Run 检索一次，默认基础资料 2000 字符、相关资料 8000 字符；每次模型请求前复核有效状态和修订。当前请求及工具配对受原上下文预算保护。停用、修正或遗忘会移除后续请求中旧的可选条目，已经发送的内容和既有聊天不承诺追溯撤回。

## 来源与事务

来源可为用户管理操作、当前任务已保存请求、已确认工具结果或已获准记忆。模型不能指定拥有者、环境或审批状态。`user_stated` 候选须引用用户请求原文；`observed` 须引用已保存工具事实，推导结论采用 `inferred`。工具来源携带真实事件序号、调用 ID、路径、hash 和不完整标记。有效来源引用本身不证明模型推断为事实。外部观察不能伪装为用户偏好。

候选按 Run/调用 ID 幂等保存，每 Run 最多 10 条、单条正文最多 2000 字符。终态 outbox 与原完成事务一同提交；处理只校验已有事实、不调用模型或重放工具，不自动激活。处理失败不改写 Run 终态，保留待办供 `memory process` 重试。候选采纳再次校验来源，修正及状态修改用修订号 CAS。

精确指纹只解决完全重复，不宣称识别语义冲突。不同内容由用户选择修正。停用可恢复。遗忘删除可召回修订正文和词项，留下不可逆的来源/派生抑制指纹；旧源重处理和索引重建不能恢复记忆。新的明确用户保存可以重新创建。原始会话、Run 和备份继续保留。

## 升级与验收

v1/v2/v3 直接升级 v4：迁移锁与会话锁、SQLite backup API、一次备份和一个事务。v3 环境 UUID 原样保留；旧状态只读查询不迁移，`state upgrade` 或必要写入才升级。旧二进制拒绝 v4；回退需匹配的旧 wheel 与升级前备份。

放行需通过身份、授权、预算、CAS、来源、遗忘、终态及 outbox 故障测试，并完成隔离 wheel 安装、三个旧版本升级、实际 DeepSeek 跨目录闭环、ConPTY、Web 及 sidecar 验证。出现越权召回、候选提前生效、遗忘再生、虚假保存成功或终态事务破坏时停止发行。开发中的测试结果不得写作最终发行验收。
