# 0.2.3 原生使用闭环

2026-09-16：本轮替代 L4a P3/P4 的发行目标，优先改善普通用户模式。
P3 的实现、失败证据和开发分支保留；未完成的隔离验收不改写为通过。

## 确定行为

- 新旧 `current_user` 任务统一使用普通用户能够访问的目录和网络。
- `cwd` 决定相对路径；保存的目录集合用作参考，不再要求逐目录 trust。
- 本机软件可直接调用，登记软件 ID 是可选的固定版本调用方式。
- LPAC 任务及曾明确启用的受限默认模式不自动降级，用户须显式转换。
- 不实现目录黑名单，不声称任意脚本无法绕过应用层约束。
- 保留任务锁、取消、Job 清理、预算、文件冲突检测、记忆审批及来源记录。
- 保持 schema v6，升级不修改 ACL、安装系统组件或触发 UAC。

## 接口边界

`ResourceGrant.file_access_scope` 明确区分 `workspace` 和 `user`，共享默认仍为
`workspace`。CLI 原生组装选择 `user`；LPAC 禁止选择 `user`。路径解析、文件操作、
发现、资源核实和软件输出检查消费同一范围，不通过放开盘根实现全局访问。

普通任务记录实际范围、位置和执行程序。旧 Run 不补写新字段，旧 trust 记录不删除。
模型记忆、资源元数据和历史仍按环境和助手身份查询，访问文件不合并任务历史。
